# Checkpoint v2.0 - Cores Reais e Fontes Nativas Resolvidas

## Conquistas Deste Checkpoint:
1. Fatiamento de caixas visuais independentes (Bounding Boxes) para tabelas, fotos e contornos.
2. Amostragem Cromática direta no Canvas HD com extração fiel de cores Hex (RGB) para cada palavra.
3. Resolução assíncrona de fontes reais via page.getOperatorList() e page.commonObjs.get.
4. Mapeamento de fontes cursivas/caligráficas e de sistema para Office (Word e PowerPoint).
5. Textos 100% editáveis no Word (.docx) e no PowerPoint (.pptx).
